# Agent Skills — punctual_alghoza deterministic data APIs

One skill: `skills/deterministic-data-apis/SKILL.md`

Teaches agents when and how to use the punctual_alghoza family of
deterministic data-transformation Actors on the Apify Store
(dedupe/normalize/verify/scrub/diff — no LLM in the conversion path).

Install:

```bash
npx skills add ahf15811987-sketch/agent-skills
```

Or point your agent at this repo, or reference
`skills/deterministic-data-apis/SKILL.md` directly.

## Actors covered

dataset-cleaner, financial-file-normalizer, kindle-clippings-parser,
marketplace-sales-normalizer, export-secrets-scanner, export-diff,
provenance-packet, crypto-export-normalizer — all under the
`punctual_alghoza` Apify Store account, all pay-per-event ($0.20–$0.30 per
successful operation), all deterministic and fail-closed.
